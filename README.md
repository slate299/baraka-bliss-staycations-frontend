## 🎯 Overview

**Baraka Bliss Staycations** is a **premium staycation rental platform** in Kenya. The frontend provides a **responsive, user-friendly interface** for guests to explore apartments, view media galleries, and submit booking inquiries.

**My Role:** Full-stack developer – implemented the **frontend**, integrated it with the backend APIs, built responsive layouts, and handled all interactive components.

> The platform aims to give guests unforgettable experiences.

---

## ✨ Features

- 🏠 **Homepage:** Hero section with brand story and featured apartments
- 🔍 **Search & Filters:** By city, price, bedrooms, and amenities
- 🖼️ **Media Gallery:** Images and videos with lightbox
- 📝 **Inquiry Form:** Submit booking inquiries with Kenyan phone validation
- 💬 **WhatsApp Integration:** Direct contact via WhatsApp
- 📱 **Responsive Design:** Works seamlessly on mobile, tablet, and desktop
- 🎨 **Smooth Animations:** Page transitions and micro-interactions

> ⚠️ Admin/operator features exist in the backend but are private and not shared in this README.

## 🚀 Getting Started (Local)

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/slate299/baraka-bliss-staycations-frontend.git
cd baraka-bliss-staycations-frontend

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Add backend URL and Cloudinary info
# REACT_APP_API_BASE_URL=http://localhost:5000
# REACT_APP_CLOUDINARY_CLOUD_NAME=your_cloud_name
```

### Run Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
